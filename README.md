# 锈土据点 · SCRAPHOLD

浏览器里的废土据点经营和防守游戏。白天派幸存者拾荒、种地、炼油、做研究，扩建据点、训练士兵；夜里变异体从锈雾里摸过来，守住炉心（地图中间的据点核心）。

## 目标

三种方式都能赢，炉心被摧毁就失败：

- **撑过二十夜**：守到第 21 天天亮。
- **摧毁母巢**：母巢在地图上按步行距离最远的地方，生命十万以上，要派一支大部队在它旁边连续围攻两三个昼夜。
- **信号塔**：派人找到 K-7 中继站，研究"旧频段破译"，在原址修好信号塔，开始广播后守住 3 晚（研究"信号增幅"后 2 晚），长明城的车队就会到。

不是每晚都有夜袭。顶栏的雾情日历显示今晚和之后 3 晚是什么夜：平静夜、夜袭、锈风暴、浓雾夜或大潮夜，可以据此安排什么时候扩张、什么时候收兵布防。大约一半的白天会弹出事件卡，选择会影响资源、人口或之后的夜晚；事件卡打开时游戏停住，天黑前不处理会按最后一个选项结算。

一局 20 个昼夜，1 倍速下大约 37 分钟，可以用 2×、3× 加速。每天天亮和黄昏开始时自动存档，刷新页面后可以从主菜单继续。

开局可以选营地特性（拾荒者营地、民兵哨所、避难所学者）、难度（简单、普通、困难）和地图种子（随机、每日、自定义）。第一次玩建议选民兵哨所、普通难度。进入游戏后，右下角有覆盖前三天的开局指引（可以折叠或关闭），随时按 F1 或点顶栏的"帮助"看完整说明。

## 操作

| 操作 | 作用 |
|---|---|
| 左键 | 选择；拖拽框选（框里有士兵时只选士兵）；双击选中屏幕内同类 |
| Shift | 加选；放置建筑时连续放置 |
| 右键 | 士兵：点地面是攻击移动，点敌人是集火；幸存者：点生产建筑或信号塔工地是派工，点受损建筑是维修；兵营：设集结点 |
| Ctrl + 右键 | 强制移动，不理会敌人 |
| K | 选中的士兵撤退回炉心附近 |
| W A S D / 方向键 / 鼠标到屏幕边缘 | 平移镜头；滚轮缩放；点小地图跳转 |
| Ctrl + 1–5 | 编队；按数字键选队，连按两次镜头跳过去 |
| Q E R Y U I B N M Z C V | 建造对应的建筑（建造菜单的按钮上标着字母） |
| X / H | 停止 / 原地坚守 |
| G | 选中空闲的幸存者 |
| F | 跳到最近的警报 |
| T / P / O | 科技树 / 政令 / 胜利目标 |
| Tab | 打开待处理的事件卡；事件卡上按 1–3 选择，Esc 先去看地图 |
| 空格 | 暂停 / 继续（暂停时仍可下令） |
| - / = | 调整速度 1× / 2× / 3× |
| Esc | 取消放置 / 清空选择 / 菜单 |
| F1 / ? | 打开或关闭说明 |

## 运行和构建

需要 Node 和 pnpm（版本见 `package.json` 的 `packageManager`）。

```sh
pnpm install      # 安装依赖
pnpm dev          # 开发服务器，浏览器打开终端里显示的地址
pnpm build        # 构建到 dist/，资源路径是相对路径
pnpm preview      # 本地预览构建产物
```

`dist/` 可以用任何静态文件服务器托管，例如 `cd dist && python3 -m http.server 8000`，然后打开 `http://localhost:8000/`。

## 测试和工具

```sh
pnpm typecheck    # 类型检查
pnpm test         # 单元测试（Vitest）
pnpm e2e          # 端到端测试（Playwright，含 3 倍速完整对局和帧率测试，约 18 分钟）
pnpm exec playwright test -c playwright.art.config.ts   # 美术截图和帧率测试
pnpm sim --seed S --days N          # 无头跑若干昼夜，打印摘要
pnpm balance --seeds 20             # 四套机器人加"什么都不做"批量对局，输出胜率和验收指标
```

代码结构见 `ARCHITECTURE.md`，第二版的验收记录见 `docs/acceptance.md`（第一版的记录在 `docs/acceptance-v1.md`）。
